Society edits

Every change a society login has made to its own data, newest first, with what the value used to be. Societies edit their own history without a moderation queue, so this is the record of what happened.

{# Said plainly rather than left to be discovered. A committee shares one login code, so this cannot name a person and must not look like it does. #}

This identifies a login, not a person. A committee shares one code, so "changed by" is the code that was used. It covers changes made through /society/ - shows, the society profile and logo, and vault listings. Moderator edits made here in /admin are not recorded. Nothing on this page can be edited or deleted; putting a value back is a normal edit.
